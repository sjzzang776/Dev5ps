Dev5ps 백테스트 체험

지표 조건과 손익비를 고르면, 팀 서비스와 같은 규칙으로 "그때 이렇게 샀다면?"을 바로 계산합니다. 데이터는 Binance BTCUSDT 1시간 봉 5,000개()이고 지표는 팀 코드로 미리 계산했습니다. 실제 서비스(FastAPI + PostgreSQL + Streamlit)를 띄우는 방법은 README에 있습니다.

진입 방식

팀 코드는 이미 보유 중이어도 새 신호마다 또 진입합니다. 두 방식을 바꿔 가며 결과가 얼마나 달라지는지 보세요.

규칙: 조건을 만족한 봉의 종가에 진입, 손절선 = 그 봉의 저가, 익절선 = 종가 + (종가 − 저가) × 손익비. 다음 봉부터 둘 중 먼저 닿는 쪽에서 청산(같은 봉에서 둘 다 닿으면 손절). 손절 폭이 0.5% 이하인 봉은 진입하지 않음. 수수료 미반영.
