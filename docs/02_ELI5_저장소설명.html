"그때 이렇게 샀다면?"
을 계산해 주는 기계

Dev5ps · 암호화폐 백테스트 플랫폼을 그림으로

01 · 먼저 알아 둘 것

캔들 한 개 = 한 시간의 요약

시작가, 가장 높았던 값, 가장 낮았던 값, 끝난 값. 이 네 숫자를 막대 하나로 그려요.

02 · 전체 흐름

모으고 → 담고 → 묻고 → 보여 준다

네 개의 상자(컨테이너)가 차례로 일해요.

03 · 핵심 규칙

들어가고, 둘 중 먼저 닿는 쪽에서 나온다

조건이 맞는 봉의 종가에 사고, 손절선(그 봉의 저가)이나 익절선 중 먼저 닿는 곳에서 팔아요.

04 · 성적표

몇 번 이겼고, 가장 크게 넘어진 건 얼마?

거래를 시간 순으로 이어 누적수익률을 그리고, 승률·기대수익·MDD(고점에서 가장 크게 떨어진 비율)를 계산해요.

05 · 부품 지도

폴더마다 맡은 역할

🧺
server-collect_data/수집기. Binance에서 받아 지표(EMA·RSI·MACD·볼린저)까지 계산해 저장
🔌
shared/창고 열쇠(DB 연결)와 코인·간격 목록
🧮
server-query/★ 계산원. filtered_func.py가 백테스트와 성적표, main_query.py가 창구(API 11개)
📺
server-frontend/화면. 전략 입력, 캔들 차트, 수익률·통계
🚚
docker-compose.yml, .github/네 상자를 함께 띄우고, 테스트 → 이미지 → 서버 배포를 자동으로
06 · 조심할 곳

신호가 연달아 켜지면, 동시에 여러 번 산다

조건이 3봉 연속 맞으면 거래 3개가 겹쳐 열리는데, 성적표는 하나씩 차례로 한 것처럼 곱해요.

⚠️ 그래서 "총 4,412회, +2,322%"는 한 계좌로 실제 거래한 값과 다를 수 있어요. 자세한 검증은 README 4절과 docs/verify/.
